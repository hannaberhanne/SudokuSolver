# Sudoku Solver

## Overview
This project implements a Sudoku solver in Python using **Depth-First Search (DFS)** and **Breadth-First Search (BFS)** algorithms.  
The solver demonstrates practical applications of graph traversal and search algorithms covered in my **Advanced Data Structures & Algorithms** course.  

## Features
- Solves standard 9x9 Sudoku puzzles.
- Implements both DFS and BFS for comparison of performance and solution paths.
- Optimized state-space traversal for improved solving time on complex puzzles.
- Modular, well-documented codebase for readability and scalability.

## Technical Details
- **Language:** Python  
- **Algorithms:** DFS, BFS  
- **Concepts:** Backtracking, Search Trees, Algorithm Optimization  
- **Structure:** Clear separation of puzzle input, solver logic, and output validation.
